# 👟 Nike Surge — UI/UX Design Project

A high-fidelity UI/UX concept built for a hackathon, featuring a modern product launch landing page for a sneaker-inspired Nike energy drink line.

## 🔗 Live Prototype
[View on Figma](https://lizard-author-57979944.figma.site)

## 🛠️ Tech Stack
- **React + TypeScript + Vite** — component-based frontend
- **shadcn/ui + Tailwind CSS** — design system and styling
- **Motion (Framer Motion)** — fluid animations and transitions
- **Canvas Confetti** — drop celebration effects
- **Figma** — original UI/UX design and prototyping

## 📂 Key Components
- `Hero.tsx` — landing hero section with sneaker inspiration switcher, live ticker, and responsive mobile navigation drawer
- `ProductHighlights.tsx` — product feature showcase with dynamic 5-flavor selector, nutrition metrics, and details modal
- `VideoShowcase.tsx` — interactive 3-chapter concept storyboard with audio pulse visualizer
- `BrandStory.tsx` — brand narrative, performance philosophy, and design lore
- `CallToAction.tsx` — conversion drop countdown, pre-order trigger, and validated newsletter signup
- `Footer.tsx` — site footer with functional internal navigation, verified official socials, and academic concept disclaimers
- `PreOrderModal.tsx` — interactive pre-order reservation flow with quantity calculation, client-side validation, and instant confirmation
- `ProductDetailsModal.tsx` — comprehensive specification sheet with nutrition facts table and tasting profile
- `StoreLocatorModal.tsx` — interactive retail locator across major Indian cities (Mumbai, Pune, Delhi, Bengaluru, Hyderabad)
- `FAQModal.tsx` — comprehensive FAQs, feedback form, and educational design attribution

## ✨ Design Highlights
- Minimalist product showcase layout with dramatic product lighting
- Mobile-first responsive design (tested across 320px, 375px, 768px, 1024px, 1440px)
- Fully accessible keyboard navigation (Escape to close modals, visible focus states, ARIA roles)
- Transparent educational concept labeling on all statistics and purchasing flows
