# 👟 Nike Surge — UI/UX Design Project

A high-fidelity UI/UX concept built for a hackathon, featuring a modern 
product launch landing page for a Nike energy shoe line.

## 🔗 Live Prototype
[View on Figma](https://lizard-author-57979944.figma.site)

## 🛠️ Tech Stack
- **React + TypeScript + Vite** — component-based frontend
- **shadcn/ui + Tailwind CSS** — design system and styling
- **Figma** — original UI/UX design and prototyping

## 📂 Key Components
- `Hero.tsx` — landing hero section
- `ProductHighlights.tsx` — product feature showcase
- `BrandStory.tsx` — brand narrative section
- `VideoShowcase.tsx` — media integration
- `CallToAction.tsx` — conversion section
- `Footer.tsx` — site footer

## ✨ Design Highlights
- Minimalist product showcase layout
- Mobile-first responsive design
- Consistent design language inspired by Nike's branding

## 🚀 Run Locally
```bash
npm install
npm run dev
```

## 🏆 Context
Hackathon submission — UI/UX track.
